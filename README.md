# PRODIGY_SD_02

This is a simple mathematical riddle game where players try to guess a one-digit number based on a clue. The program shows a riddle stating that when the number is squared, it equals the number added to itself. Players get 3 attempts to guess the correct number (which is 2, since 2² = 4 and 2 + 2 = 4). The game provides feedback after each guess and reveals the answer if the player doesn't guess correctly within the attempts.
